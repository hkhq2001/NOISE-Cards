# NOISE XO

لعبة XO جماعية مباشرة: مشرف، لاعبين موزعين على فريقين، ومشاهدون.

## التشغيل
1. استخدم Node.js 18 أو أحدث.
2. داخل مجلد `noise-xo` شغّل `npm install`.
3. شغّل `npm start`.
4. افتح `http://localhost:3000`.

## النشر على Render
- أنشئ Web Service واربط مستودع GitHub.
- Root Directory: `noise-xo`
- Build Command: `npm install`
- Start Command: `npm start`
- اترك Render يحدد PORT تلقائياً.

## قواعد اللعبة
- يضيف المشرف اللاعبين ويحدد الفريق X أو O.
- اللاعب يدخل بالاسم نفسه الذي سجله المشرف.
- أعضاء كل فريق يتناوبون تلقائياً.
- المباراة من ثلاث جولات؛ أول فريق يحقق فوزين يحسمها.
- المشاهدون يدخلون برمز الغرفة أو رابط المشاهدة.

## ملاحظات مهمة
هذه نسخة MVP أولية. بيانات الغرف محفوظة في ذاكرة الخادم وتُمسح عند إعادة تشغيله. يلزم استضافة Node.js تدعم Socket.IO؛ GitHub Pages وحده لا يشغّل الخادم. أضف قاعدة بيانات وتوثيقاً أقوى للمشرف قبل استخدامها في بطولة عامة.
